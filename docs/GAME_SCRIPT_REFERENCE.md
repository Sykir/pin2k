# `game_script.json` Format & Gamecode Extraction Reference

This document specifies the **`game_script.json`** format (schema `v1`) generated by `pin2k-rom-tool extract-gamecode` and executed by `ScriptRuntime` in `pin2k-core`.

---

## 1. Extraction Pipeline (`extract-gamecode`)

`pin2k-rom-tool extract-gamecode` inspects `game.rom` + `symbols.rom` (and optionally `prism_flat.bin`):

1. **Hardware Table Resolution in `.data`**:
   - `DriveTable`: 48 entries × 24 bytes (`flags`, `default_pulse_ms`, EN/DE/FR/ES names).
   - `LampTable`: 128 entries × 36 bytes (`flags`, EN/DE/FR/ES names).
   - `SwitchTable`: 96 entries × 48 bytes (`sw_type`, `handler_addr`, `arg`, `debounce_ms`, EN/DE/FR/ES names).
2. **Static x86-32 Disassembly (`lift_x86_calls`)**:
   - Scans each `swd_*` handler up to `RET` (`0xC3`/`0xC2`).
   - Records every `CALL rel32` (`0xE8`) resolved via `symbols.rom` along with pushed arguments (`PUSH imm8` `0x6A`, `PUSH imm32` `0x68`).
   - Translates `generic_score`, `score(u64)`, and `AudioRequest(desc*)` calls into `ScriptAction` (`AddScore`, `PlaySound`).
3. **Rules, Modes & Attract Export**:
   - Emits `meta` (auto-detected Trough, Shooter Lane, Start Button switches), `hardware`, `attract`, `vars`, `modes`, and `rules`.

## 3. Triggers, Conditions & Actions

### `ScriptTrigger` (`trigger.type`)

| Type | Parameters | Fires When |
|---|---|---|
| `on_boot` | — | Script is loaded via `Pin2kMachine::load_game_script` |
| `on_ball_start` | — | New ball starts (`start_ball()`) |
| `on_ball_end` | — | Ball drains (`on_ball_drained()`) |
| `on_switch` | `sw_id: u8` | Logical switch `sw_id` closes in-game |
| `on_tick` | — | Every 60 Hz (`16 ms`) tick in-game |
| `on_mode_enter` | `mode: String` | Mode `mode` is activated |
| `on_mode_exit` | `mode: String` | Mode `mode` ends or expires |
| `on_timer` | `timer: String` | Countdown timer `timer` reaches `0` |

### `ScriptCondition` (`conditions[].op`)

| Operator | Parameters | Semantics |
|---|---|---|
| `ball_in_play` | — | True if `balls_in_play > 0` and state is `InGame` |
| `not_tilted` | — | True if machine is not in `Tilt` state |
| `mode_active` | `mode: String` | True if `mode` is active |
| `mode_inactive` | `mode: String` | True if `mode` is inactive |
| `var_eq` / `var_ge` / `var_lt` | `var: String, value: i64` | Compares active player's `var` (or `global_*`) to `value` (`==`, `>=`, `<`) |
| `bit_set` / `bit_clear` | `var: String, bit: u8` | Tests bit `bit` (`0..63`) of `var` |

### `ScriptAction` (`actions[].action`)

| Action | Parameters | Effect |
|---|---|---|
| `add_score` | `points: u64` | Adds `points` (× multiplier) to the active player |
| `set_var` / `inc_var` | `var: String, value / delta: i64` | Sets or increments per-player variable (`global_*` also updates global map) |
| `set_bit` / `clear_var` | `var: String, [bit: u8]` | Sets a bit or clears `var` to `0` |
| `pulse_drive` | `drive_id: u8, ms: u8` | Pulses solenoid/flasher `drive_id` for `ms` milliseconds |
| `set_lamp` | `lamp_id: u8, on: bool` | Turns lamp `lamp_id` on or off |
| `play_sound` / `play_music` | `sound_id: u16` | Plays a DCS one-shot SFX or looping music track |
| `play_anim` | `anim: String` | Displays animation `anim` (key in `gfx_manifest.json`) |
| `show_banner` | `text: String` | Shows status banner text for 3 s |
| `start_mode` / `end_mode` | `mode: String` | Starts or terminates a mode (`modes[]`) |
| `start_timer` | `name: String, ticks: u32` | Starts a countdown timer decremented each 60 Hz frame |
| `start_multiball` | `balls: u8` | Queues extra balls until `balls` are in play |
| `award_extra_ball` | — | Awards an Extra Ball to the active player |
| `advance_scene` | — | Advances or starts the active Holoprojector scene |
| `collect_bonus` / `eject_ball` | — | Collects bonus / requests ball ejection |

## 4. Extracted UI Layout Database: `rom_layout_db.json` (`extract-layout`)

Alongside `game_script.json`, **`pin2k-rom-tool extract-layout --elf <PATH> --output-dir <DIR>`** extracts **`rom_layout_db.json`** directly from an i386 ELF32 binary (`swe1_0200.elf` / `rfm_0195.elf`):

```json
{
  "schema_version": 1,
  "elf_symbols_count": 14841,
  "deff_count": 138,
  "player_names": ["Qui-Gon", "Jar Jar", "Anakin", "..."],
  "score_coords": [ ... ],
  "saber_table": [ ... ],
  "kahuna_flare_colors_rgb555": [31750, 800, 31, "..."],
  "scenes": [ ... ],
  "attract_sequence": [ ... ],
  "acd_commands": [ ... ],
  "ard_descriptors": [ ... ],
  "deffs": [
    {
      "class_name": "DeffScoreDisplay",
      "methods": [ ... ],
      "all_anims": [ ... ],
      "all_fonts": [ ... ],
      "all_z_priorities": [9, 10],
      "all_colors_rgb555": [32767, 29414],
      "all_audio_requests": [ ... ]
    }
  ]
}
```

This metadata powers the pure-Rust screens in `pin2k-core` (see [SCREEN_LAYOUT_REFERENCE.md](SCREEN_LAYOUT_REFERENCE.md)) and provides the foundation for full data-driven UI rendering.
